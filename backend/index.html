About Pulse

What is Pulse?

Pulse is a heart monitoring dashboard designed to help users track their cardiovascular health including BPM and oxygen levels.

Features

  • Real-time BPM tracking
  • Pulse history graph with Chart.js
  • Oxygen level overview
  • Custom profile management
  • Secure login system

Technology Used

Built using HTML, CSS, JavaScript, and Chart.js for data visualization.
